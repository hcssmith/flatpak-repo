## reinstalling from scratch

Everything needed after wiping the laptop. Installing Neovide pulls the Nvim base app — config, parsers, ripgrep and clipboard tools — automatically. 

$ flatpak remote-add hcssmith https://flatpak.hcssmith.com/hcssmith.flatpakrepo
$ flatpak install hcssmith com.hcssmith.Neovide
